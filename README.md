# ITJobsNB
# NB IT Jobs Tracker

A weekly job aggregation tool that collects Information Technology jobs
in New Brunswick, Canada, categorizes them, and exports structured data.

## Sources
- Job Bank Canada
- CareerBeacon
- NBJobs
- Indeed (link-out only, no scraping)

## Categories
- Software Developer / Engineer
- IT Support / Helpdesk
- Data / Analytics
- Networking and Infrastructure
- All IT Jobs
